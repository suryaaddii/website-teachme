
# TeachMe — Educational Landing Page

A responsive educational landing page designed to introduce tutoring services through a clean and accessible web interface.

## Live Demo

**[View Website](https://suryaaddii.github.io/website-teachme/)**

## Overview

TeachMe is an educational website project focused on presenting tutoring services through a responsive landing page.

The website was developed by customizing an existing Bootstrap-based template to suit the educational service context.

## Project Focus

- Educational service presentation
- Responsive web design
- Landing page customization
- Frontend development
- Website content customization
- Static website deployment

## Tech Stack

| Technology | Purpose |
| --- | --- |
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| JavaScript | User interface interactions |
| Bootstrap | Responsive UI framework |
| GitHub Pages | Website hosting |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/suryaaddii/website-teachme.git
cd website-teachme
```

Open `index.html` in a web browser or use a local development server.

## Deployment

The website is hosted using GitHub Pages.
